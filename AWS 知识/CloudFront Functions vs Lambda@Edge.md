| 特性      | CloudFront Functions                | Lambda@Edge              |
| ------- | ----------------------------------- | ------------------------ |
| 运行时环境   | JavaScript                          | Node.js 或 Python         |
| 最大执行时间  | 小于 1 毫秒                             | 5 秒 (查看器事件) / 30 秒 (源事件) |
| 内存限制    | 2 MB                                | 128 MB 至 10 GB           |
| 网络/文件访问 | 不支持 (不能调用外部 API)                    | 支持 (可以访问数据库、S3 等)        |
| 价格      | 极低（$0.1/百万次）                        | 较高（$0.6/百万次 + 计算费用）      |
| 场景      | 修改 HTTP Header、Cookie 或 URL 重写等简单场景 | 修改 Request Body 等复杂场景    |
