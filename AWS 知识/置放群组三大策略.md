| 特性        | 集群 (Cluster)            | 分布 (Spread)     | 分区 (Partition)               |
| ------------- | --------------------------- | ------------------- | -------------------------------- |
| 物理布局      | 所有实例挤在同一个可用区同一个机架（或物理临近的机架） | 每个实例占用一个独立的机架       | 将实例分成组，每组（分区）占用独立机架              |
| 隔离粒度      | 无（全在一起）                     | 实例级（Instance level） | 组级（Group level）                  |
| 跨可用区 (AZ) | 不支持                         | 支持                  | 支持                               |
| 网络性能      | 最高                          | 正常                  | 正常                               |
| 容灾能力      | 最低（机架坏了全挂）                  | 最高（单机故障互不影响）        | 中等（按分区隔离风险）                      |
| 实例数量限制    | 视账户配额而定，通常较多                | 极少（每可用区通常 7 台）      | 多（可容纳数百台实例）                      |
| 核心目的      | 追求极致速度                  | 追求极致安全          | 平衡规模与安全                      |
| 典型应用场景    | 高性能计算 (HPC)、视频渲染、低延迟分布式训练   | 核心数据库主备节点、关键业务服务器   | 大数据处理 (Hadoop, Kafka, Cassandra) |
