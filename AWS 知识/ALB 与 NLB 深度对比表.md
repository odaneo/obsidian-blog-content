| 特性       | ALB                       | NLB                                    |
| -------- | ------------------------- | -------------------------------------- |
| OSI 模型层级 | 第 7 层（应用层）                | 第 4 层（传输层）                             |
| 主要协议     | HTTP, HTTPS, gRPC, HTTP/2 | TCP, UDP, TLS                          |
| 处理对象     | 基于请求内容（如 URL 路径、Header）   | 基于 IP 数据包和端口，每个单独的TCP链接在有效期内，只会路由到单个目标 |
| 性能/延迟    | 毫秒级延迟，适合复杂的业务逻辑           | 微秒级延迟，适合超高并发和低延迟                       |
| IP 地址类型  | 动态 IP（通过 DNS 域名访问）        | 静态 IP（可绑定弹性 IP/EIP）                    |
| 核心功能     | 路径转发、主机名转发、重定向、身份验证       | 极高的吞吐量、保留源 IP、处理突发流量                   |
| 健康检查     | 基于 HTTP 状态码（深入应用层）        | 基于 TCP 连接或 ICMP（基础连通性）                 |
