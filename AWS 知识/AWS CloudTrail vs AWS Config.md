| 维度   | AWS CloudTrail         | AWS Config                |
| ---- | ---------------------- | ------------------------- |
| 主要功能 | API 调用和用户活动记录          | 资源配置跟踪和合规性评估              |
| 着眼点  | 谁在什么时候通过哪个 IP 删除了这个安全组 | 这个安全组现在的规则是什么，是否符合公司的安全标准 |
| 关注点  | 动作：API 请求的具体细节         | 状态：资源的配置快照                |
| 合规性  | 提供操作记录用于事后审计           | 自动检测资源是否合规                |
