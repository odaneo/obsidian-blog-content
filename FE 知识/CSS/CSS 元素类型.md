| 元素类型      | 换行情况 | 宽高设置    | margin 和 padding  | 常见示例                                            |
| --------- | ---- | ------- | ----------------- | ----------------------------------------------- |
| **行内元素**  | 不换行  | ❌不可设置宽高 | ✅ 左右有效，⚠️ 上下无布局效果 | `span`, `a`, `img`, `strong`, `em`              |
| **块级元素**  | 自动换行 | ✅可以设置宽高 | ✅ 上下左右均有效         | `div`, `p`, `h1~h6`, `ul`, `ol`, `li`, `header` |
| **行内块元素** | 不换行  | ✅可以设置宽高 | ✅ 上下左右均有效         | `button`, `input`, 设置了`inline-block`的元素         |
