
| 修饰符         | 用法    | 功能                   | 示例                                          |
| ----------- | ----- | -------------------- | ------------------------------------------- |
| `sealed`    | 类、方法  | 禁止继承类；禁止重写虚方法        | `sealed class A {}`                         |
| `abstract`  | 类、方法  | 强制继承并实现；不能实例化        | `abstract class A { abstract void Run(); }` |
| `virtual`   | 方法、属性 | 允许在子类中被 `override`   | `virtual void Speak()`                      |
| `override`  | 方法、属性 | 重写父类的`virtual`方法     | `override void Speak()`                     |
| `readonly`  | 字段    | 只能在构造函数中赋值一次         | `readonly int a = 5;`                       |
| `const`     | 字段    | 编译时常量，值不可变           | `const int b = 10;`                         |
| `private`   | 类成员   | 仅在类内可访问              | `private int _x;`                           |
| `protected` | 类成员   | 仅本类及其子类可访问           | `protected void Foo()`                      |
| `internal`  | 类、成员  | 仅同一程序集（dll，或者exe）可访问 | `internal class A {}`                       |
| `static`    | 类、成员  | 不可实例化或与实例无关          | `static class Util {}`                      |
