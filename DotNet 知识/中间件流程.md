
```c#
app.UseRouting();
app.UseAuthentication();
app.UseAuthorization();
app.UseEndpoints(endpoints =>
{
    endpoints.MapControllers();
});
```

所有中间件共享同一个 `HttpContext` 对象，它包括：

- `Request`
- `Response`
- `User`
- `Items`（跨中间件传值）
- `Session`（若启用）

```shell
浏览器请求
   ↓
【Kestrel 服务器】
   ↓ 创建 HttpContext
【ASP.NET Core 中间件管道】
   ↓ 每个中间件接收并可能修改 HttpContext
【最终处理逻辑（如 Controller Service Repository）】
   ↓ HttpContext.Response 输出结果
浏览器收到响应
```
