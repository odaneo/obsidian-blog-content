
| 项目     | 基本类型 (number, bool, etc.)         | 引用类型 (object, array, class, list, etc.)    |
| ------ | --------------------------------- | ------------------------------------------ |
| 传递的内容  | 值本身（拷贝副本）                         | 引用（地址）（指向同一个对象）                            |
| 函数内部修改 | 修改的是副本，不影响外部                      | 修改的是对象本身，影响外部                              |
| 举例（C#） | `int`, `bool`, `double`, `struct` | `string*`, `List<T>`, 自定义 `class` `record` |
| 举例（JS） | `number`, `boolean`, `string`     | `object`, `array`, `function`              |

- 注意：C# 的 string 是引用类型，但不可变（修改时是新建新对象）。但如果写成了 char[]，就是可变类型。
