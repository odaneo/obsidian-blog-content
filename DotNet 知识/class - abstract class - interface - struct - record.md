
| 特性          | class                            | abstract class          | interface                         | struct        |
| ----------- | -------------------------------- | ----------------------- | --------------------------------- | ------------- |
| 类型          | 引用类型                             | 引用类型                    | 引用类型                              | 值类型           |
| 是否能实例化（new） | ✅ 可以                             | ❌ 不能，必须继承后用             | ❌ 不能，必须实现后用                       | ✅ 可以          |
| 是否能继承       | ✅ 可以继承一个 class，还可以实现多个 interface | ✅ 可以继承一个 abstract class | ❌ 不能继承，只能实现                       | ❌ 不能继承 struct |
| 是否能被继承      | ✅ 可以                             | ✅ 必须被继承                 | ❌ 不继承，只实现                         | ❌ 不能被继承       |
| 是否可以有方法实现   | ✅ 可以                             | ✅ 可以（也可以有 abstract 方法）  | ❌ 不能，有默认实现除外（C# 8之后支持 default 方法） | ✅ 可以          |
| 字段/属性       | ✅ 可以有                            | ✅ 可以有                   | ❌ 传统上不能有字段（C# 8后可以有静态字段）          | ✅ 可以有         |
| 构造函数        | ✅ 有                              | ✅ 有（但不能实例化）             | ❌ 没有实例构造函数（可以有静态）                 | ✅ 有（但无参构造限制）  |
| 主要用途        | 普通对象                             | 作为模板、半成品父类              | 规范、契约接口                           | 小型数据对象        |

| 特性            | `record`         | `class`      |
| ------------- | ---------------- | ------------ |
| 默认比较方式        | ✅ 值相等（值比较）       | ❌ 引用相等（指针比较） |
| 支持 `with` 表达式 | ✅ 有              | ❌ 无          |
| 解构            | ✅ 有              | ❌ 无          |
| 推荐场景          | DTO, 响应模型, 配置对象等 | 业务逻辑类、实体类等   |
`record` 主要用来定义不可变数据模型
