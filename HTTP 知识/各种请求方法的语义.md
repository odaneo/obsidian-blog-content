| **请求方法** | **主要用途**              | **幂等性** | **备注**           |
| -------- | --------------------- | ------- | ---------------- |
| GET      | 从服务器检索资源              | 幂等且安全   | 不产生副作用           |
| POST     | 提交数据以创建新资源或进行处理       | 非幂等     | 可能产生副作用，多次请求结果不同 |
| PUT      | 完全替换资源（更新或创建）         | 幂等      | 重复请求结果一致         |
| PATCH    | 对资源进行部分更新             | 部分幂等    | 仅修改资源的部分内容       |
| DELETE   | 删除指定资源                | 幂等      | 重复删除无额外副作用       |
| HEAD     | 获取资源的响应头信息            | 幂等且安全   | 不返回响应体           |
| OPTIONS  | 查询服务器支持的 HTTP 方法及其它选项 | 幂等且安全   | 常用于跨域预检          |
